What do HTML, CSS and C do?

HTML gives a page its structure and CSS controls how it looks. C is a programming language, and it is one of the tools I am learning so far.

So far, my first lessons have been about writing instructions a computer can follow and building simple pages with HTML and CSS. It is a big change from just using apps and websites, because now I get to see how they are made.

Seeing my own code turn into something I can open in a browser makes the course feel real to me.

Reflection

Making this page taught me how HTML gives a page its structure and how CSS controls its look. My earlier About Me activity was a simple page, so this time I organized everything into clear sections with headings, cards, a link, and a photo that changes on hover. I also added a class schedule table, a menu that stays on top, and questions you can click open.

What did I learn?

HTML is the structure of a page and CSS is its style.

What was my biggest challenge?

One wrong file path can break a page, so I check my paths carefully now.

What habit did I pick up?

I plan the content before I start coding.

What will I do next time?

I will test the page on my phone earlier, because testing early saves a lot of time.

The hardest part was keeping the page easy to read while making it look better than my first version. I learned that good spacing and a small set of colors do more for a page than adding lots of effects.

Small details matter, and testing early saves a lot of time.
