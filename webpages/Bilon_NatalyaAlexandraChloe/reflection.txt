My path into computing
My curiosity about hacking and how computers work helped me become interested in Computer Science. My mom also inspired me to learn more about technology and computer security. I chose this course because I want to challenge myself, understand how software and systems work, and learn how to protect information responsibly. I hope to keep improving my problem-solving skills and become more confident with programming.

Reflection
Creating this personal website helped me understand how HTML and CSS work together. I learned that HTML gives a webpage its structure through headings, paragraphs, links, images, lists, navigation, and tables, while CSS controls its appearance, spacing, colors, and layout. I also practiced using semantic elements, Flexbox, CSS Grid, and media queries to make the page responsive on phones and computers.

Compared with my About Me activity, I improved the way I organize information into clear sections and present it with a consistent design. I also learned to use an image file path correctly, add alternative text for accessibility, and include comments that explain important parts of my code. Choosing a pastel yellow, pink, white, blue, and purple palette helped me make the website feel more personal. I learned that building a website takes patience, checking details, and making small improvements step by step.
