Reflection

I realized that creating a website requires more time, patience, and effort than I originally expected. At first, I thought designing a webpage would be simple, but as I started working with HTML and CSS, I realized that there were many things I needed to understand and consider. HTML was quite easy to learn, but CSS was more challenging because it required proper styling, spacing, and arrangement of elements. Despite the difficulties, I learned that having a clear layout and following each step made the process much easier. In the end, I was able to complete my webpage and gained a better understanding of how HTML and CSS work together to create a website.
